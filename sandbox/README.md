# Sandbox

The user-facing workbench, built with [Sandkit](https://github.com/sebjwallace/sandkit). It shows how the machine works, step by step, using the real engine from `../src/`.

**Open:** double-click `index.html` (it must stay inside the repo, as it loads the engine from `../src/`). The first page, *The basics*, learns from 200 pictures while it loads, which takes a few seconds.

For agents: read `AGENTS.md` first.
