# Theories

Longer theory notes: ideas about how the machine could work, worked out in conversation, before (or while) they are
tested. Speculative unless a note says otherwise; each says which experiments support it. The settled core is in
[philosophy](../philosophy.md) and [principles](../principles.md); what has been tested is in the
[checkpoints](../checkpoints/README.md).

| Note | About |
|---|---|
| [Architecture and regulation](architecture-and-regulation.md) | Many regions, each the same engine with a few settings, wired by a few connection types; heat as distance from each region's own stasis, activity as how it gets back; the machine self-driven through what its regions leave unresolved. |
| [Feelings as heat](feelings-as-heat.md) | Human feelings read as heat and its flow: trapped heat as distress, patching as rationalisation, outward heat as curiosity, coherence as fulfilment; set points, resolving rather than masking, and the machine's purpose. |
