# Distillation

Distillation (CTR-2 DEF-10) turns an exploring result into one that fulfils the contracts: read the experiments behind
it against both contracts, list every violation clause by clause (CTR-2 CON-7), then remove them one at a time,
measuring after each. A result that survives a removal never depended on it; one that falls shows what the violation
was doing. Each distillation has a code (D-01, ...) and a file listing its violations and the steps taken.
