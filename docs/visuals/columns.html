Columns: expanding the input so memories don't collide

From input cells to columns to assemblies, and why two memories that share inputs stay apart. Builds on the visual language. Drawn by hand to show the idea; not a run of the engine.

How to walk through it

Press Next and watch the bottom row first, then the columns above it. Step 1 is the input: nine input cells, four of them on. On step 2 a column of 18 cells appears over each input cell. On step 3, look for one teal dot in each column whose input is on: each input has become one particular cell. On step 4 teal arcs join those cells; that is assembly A, nothing more than the cells and their links. On step 5 comes pattern B, in coral. Look at the three amber inputs it shares with A, then up at their columns: B's dots are different cells from A's in the same columns. Step 6 holds both at once, and teal and coral never touch a common cell. Step 7 is a cue: only two teal cells are lit, the rest of A comes back as rings, and B stays dark even though it uses the same inputs. Step 8 takes the columns away, so the arcs sit on the input cells themselves. Teal and coral now share the amber inputs, and the cue reaches the partners of both, which brings back a blend.

What it shows

A column over each input cell is dimensionality expansion: nine inputs become 162 cells, so each input is no longer one thing but a population. An input that is on activates one cell in its column, and which cell depends on context. Two patterns that overlap on the input can then use different cells and different links, so both can be held, and recalled, without colliding. These are sparse distributed representations (CTR-1 CAP-2), and recall from part of an assembly is auto-associative memory (CAP-3).

Without columns, as in a classic Hopfield network, each input cell is a single unit, so every memory that uses it is linked on that same unit. Memories that share inputs blur together, and a cue on shared inputs brings back a mixture. That crosstalk is what the columns remove.

What's simplified

The separation is only as good as what picks the cell. If two patterns happen to land on the same cell in a shared column, they collide there. In Anneal's pictures the cell is chosen by where the input sits. In text, choosing it by context alone fails: in the owner's earlier work (sketch 20), cells chosen by what came before encoded the frame, not the word, so different words in the same frame shared cells (recall 52%); choosing per word gave 88%. A choice from both, context and word, was never built (answers). More cells per column means more room before two things collide by chance. The links are drawn as lines between cells; how a cell actually holds its links (segments and synapses) is the next visual. One cell can also belong to many assemblies, which brings back a collision inside the cell; segments are what solve that.
