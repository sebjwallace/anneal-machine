# 004 · One floor per level for assemblies

**What:** each column's cells come in floors: floor 0 holds where things are, and each composite level has its own floor for its assemblies.

**Why:** levels never collide. With a single shared floor, 3 of 28 pairs of composites at different levels shared cells.

**Open (owner's decision):** a shared floor would let similar things on different levels overlap (share cells), at the cost of occasional collisions.
