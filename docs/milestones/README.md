# Milestones

The Anneal engine was built in steps. Each step has a note, written for anyone explaining the machine to others, including the sandbox. The names follow the life of a casting; each has a plain subtitle.

| # | Note | In plain words |
|---|---|---|
| 01 | [Smelt](01-smelt.md) | pulling parts out of raw pictures |
| 02 | [Heat](02-heat.md) | one currency for cost |
| 03 | [Pattern](03-pattern.md) | one shape, recognised anywhere |
| 04 | [Cast](04-cast.md) | many castings from one pattern |
| 05 | [Grain](05-grain.md) | what's inside, as cells |
| 06 | [Mould](06-mould.md) | the whole, from a part |
| 07 | [Transition](07-transition.md) | one state into the next |
| 08 | [Stamp](08-stamp.md) | a change learnt once, applied anywhere |
| 09 | [Fettle](09-fettle.md) | cleaning off what doesn't belong |

Every note has the same sections:
1. **In one paragraph**
2. **Why it matters**
3. **How it works**
4. **What it showed**
5. **What to show people**
6. **Limits and open questions**
7. **Where it lives**

Use only the words in [the glossary](../glossary.md). The deeper why is in [philosophy](../philosophy.md), the rules in [principles](../principles.md), and the code's surface in [engine-api](../engine-api.md).
