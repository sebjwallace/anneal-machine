# Experiments

Scratch space: rough, contained, and with copies of code wherever that's easier. Nothing here is the main line (that's `src/`).

| Folder | Contents |
|---|---|
| `sketches/` | One folder per experiment (C02-C27): its runner, and usually a `viewer.html` page. |
| `findings/` | What each experiment found. |
| `models/` | The model code each experiment used, kept as it was. |
| `world/` | The pattern catalogue and the moving-things world. |
| `viewer/` | The shared page builder for the earlier experiments. |

To run one: `node experiments/sketches/<name>/run.js`. Retired experiments can move to `archive/`.
