# Milestone experiments

- **C16 / C17:** decomposition and composition by comparison: shared overlap becomes a part, recurring arrangements become composites.
- **C18:** shift invariance: learn once, recognise anywhere.
- **C19:** many instances of the same thing in one picture.
- **C20:** total energy = structure + flow; every rest change measured.
- **C21:** primitives as columns, cells as coordinates, composites as assemblies.
- **C22:** completion from part of a picture and from a few cells.
- **C23:** transition memory (states and transitions, cues, context, branches).
- **C24:** shared changes: a change learnt once applies in new places.
- **C26:** the crutches taken out, leading to the engine in `src/`.
