# C160 · Keeping what episodes share (a taste)

C159's taste, with the binding rule also binding each frame with the overlap of its new view and each earlier one, so
that what a frame's episodes share (the sign, the 0 carried in) is kept beside the cluttered episodes. Right answers
rose from 7 to 24% to 69 to 88% across additions, subtractions, single-digit and long-row multiplications, with one
wrong frame in 320. 10 to 30% of sums still recall nothing, likely because some overlaps kept digits two sums shared
by coincidence. Next: more examples, to see whether coincidences wash out; then let the engine find overlaps itself.
