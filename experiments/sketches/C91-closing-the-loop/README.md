# C91 · Closing the loop

The whole cycle of the owner's picture in one machine: talk turns the surface, the deep warms where it turns, a new piece
settles at the surface and sinks only where it meets warm ground; it stays up on cold ground and evaporates if it fits
nowhere ([model.md](model.md)). Hypothesis, predictions, findings: [hypothesis.md](hypothesis.md),
[PREREG.txt](PREREG.txt), [findings.md](findings.md).

**Run:** `node run.js` (a few seconds; `SEEDS=1` is the development seed).

**In short:** it works as one cycle, every seed alike: "cat mammal" sinks after talk of walking and waits otherwise;
"cat flies" evaporates; the deep takes in a quarter of the false links, against all of them when it learns everything.
But context decides belief: after talk of swimming, "fish mammal" sinks too. And "bird walks" (true, new) still can't
get in.
