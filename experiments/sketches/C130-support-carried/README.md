# C130 · Support carried

Distillation D-03, V1b. C129 found pieces through the engine's own bonds, but choosing between overlapping pieces by
the engine's competition cost up to 5%. Here the competition rule is kept exactly (most support wins, ties held). Only
support changes: it is what a way of reading saves, in the currency, carried from the winner it continues, and
competition happens as each letter arrives. It reads exactly as the computed cheapest description on both books,
every figure equal. Reading is now distilled apart from one change for the owner to judge: support counted in the
currency instead of counted minus missing.
