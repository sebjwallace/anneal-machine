# C145 · Rivals from place

One new rule in the engine: two members compete if they have never been in an assembly together but share company.
Not told which digits compete, it finds the five places in the facts of addition. With it, the engine keeps every
right written digit and drops every wrong one (9,000 of 9,000; 0 without it); a completed fact holds still instead of
spreading; and column addition with the units digit judged by the engine is identical to before (100% on 4 to 8 digits).
The fit test for the units digit is now the engine's.
