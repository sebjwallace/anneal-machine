# C167 · A jump, and letting go

All by hand. When a cue starts a procedure at a place, the binding rule binds that place into the procedure. A jump
then brings the focus straight back there. When the last way of working ends, the procedure lets go by competition
(Done is an alternative to the procedure renewing itself). In all 200 sums: worked, jumped back to the start, copied,
let go, and went quiet by itself. Controls: with no start bound the jump goes nowhere; with no Done the procedure stays
held. But in a second sum in the same memory, the jump brought on both sums' starts (50 of 50), because a bound place is
permanent. The next question is a temporary binding, a latch.
