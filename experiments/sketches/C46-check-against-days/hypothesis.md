# C46 · Check a plan against remembered days

Owner's idea: before testing a plan in the world (slow, costly, sometimes impossible), check it against remembered
experiences. Where plan and memory agree, energy is low; where a memory contradicts it, energy is high: a misfit.
C45's joining invented roads because general shapes treat linked choices as free. Here the machine also keeps the
days themselves, and every joined route is played back against them, link by link, with the ordinary recall rule
(do these two places sit one step apart, in this order, inside some kept day?). Hoped: invented roads caught, genuinely
new routes (each link lived, the whole never walked) let through. Also: how many days need keeping (all, 100, 30)?
Run: `WIN=300|1000 DAYS_KEPT=30|100 node run.js`.
