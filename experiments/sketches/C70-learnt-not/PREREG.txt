Changed on the dev seed before this file (reported in NOTE.md):
 - part 2/3 first used a hard block (entity rejected if inhibition >= 1.0). It deadlocked: an entity blocked by inhibition can never be
   selected, so its inhibition can never be unlearnt. Replaced by: inhibition subtracts from the matched support
   (acceptable only if #matched - I > 0 and #matched - I >= #missing); I is also added to the score.
 - balance acts on every potential inhibitory link from an active cell/column to a driven cell (Vogels' rule acts on all inhibitory
   synapses), not only on links that misfit already created.
