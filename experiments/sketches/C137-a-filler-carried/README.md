# C137 · A filler carried

The first sketch on learned computation. A two-moment frame ("put" with an animal, then "in" with the same animal) is
taught with "cat", "dog" and "hen". The test is whether "put" "fox" becomes "in" "fox", though "fox" has never been in
the frame. It does, in one arm only: transitions learnt only on what changed, with holding and handing on. The filler
is carried with no binding to the frame. Two failures: the trained filler "cat" fails everywhere, because its memorised
moment holds "put" on; and nothing lets go of "fox" when "cat" arrives, because rivals come only from transitions and
"fox" is in none.
