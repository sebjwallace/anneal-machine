# C50 · Can narrow assemblies join up? (out-hub.txt, out-small.txt, out-grid.txt)

General memory holds only assemblies with slots (C49: they settle narrow). Joining by pushing from both ends (C44), with
plans checked against the store of experiences (C47).

**Hub (every start with every end is real; A → J → Q and B → J → P never shown).** With enough experience (1,000 walks)
both held-back walks are found and trusted. At 300 walks one of them; at 100, neither.

**Parks (paths that branch, so some combinations are not real).** Made-up walks are produced often (small park 9, grid 18
by 3,000 days) and **every one is caught**. Real new walks are found less often than when memory also keeps plain walks
(C47): small park 0, grid 2.

**Result.** Several narrow assemblies active together can reach what one broad assembly would, where the world really
is "any start with any end" (the hub). In branching worlds, narrow general memory alone finds fewer real new walks, and
the store of experiences is doing most of the work by catching what it makes up.
