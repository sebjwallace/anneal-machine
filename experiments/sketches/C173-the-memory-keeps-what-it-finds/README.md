# C173 · The memory keeps what it finds (a taste)

One memory works six worked examples of long multiplication's two rows. It keeps what settles (binding a copy of the
recall link on settling), recalls by competition with copies counting at the hand-over, tries its own offers when recall
doesn't settle, and is tested, all without being rebuilt or copied. Repetition removed the search's coincidences. Three
equally right second-row ways of working stayed tied for ever with no tie-break (second row 0 of 200 at test). With a
declared "first formed wins" tie-break, one won once, then kept winning by repetition (200 of 200).
