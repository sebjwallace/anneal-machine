# C107 · A piece feels its own price

C106's rule (keep a piece only if it makes the whole description cheaper) made by each piece from what it holds: its
own body, its own uses, its own naming cost. It keeps every piece the global total keeps, then forms extra ones (20
against 12 on the prose), because it can't feel that each new piece makes every other piece's uses dearer to name.
Without its naming cost it falls apart into two-letter scraps; forming the moment a piece first pays, while streaming,
cuts at coincidences. What's missing from the local rule is one shared quantity: how crowded memory already is.
