One energy: seeing and change in one bill

Two learners watch the same short sequences of moving objects. Each object is a base (table moves right, frame moves down, cart moves left) with a top on it (cap, peak, dots, hook). Two pairs are never shown while learning: frame + dots and cart + peak. The plain engine pays only for seeing. One energy also pays for remembering how things change, so a kind (one base, several tops) that lets one change cover every version becomes worth keeping. The learners run in your browser.

Test: what happens next?

Pick an object and a fresh sequence is made. Each learner explains the picture with what it knows (colours = which thing it saw), then predicts the next picture by moving every thing the way it usually moves.
