# C144 · The facts in memory

The single-digit facts of addition (three digits in; units and tens out) formed as 1,000 assemblies in the engine and
recalled by completion: 1,000 of 1,000 exact. Column addition (C143's best search, C142's test) with every fact recalled
from the engine instead of looked up: identical results, 100% on 4 to 8 digits. But completion can't judge a written
digit: given a wrong one, the engine never rejects it, brings on the right digit beside it, and also opens the facts
that would have made the wrong digit right (patching). Rejecting needs rivals from place, which the engine doesn't have
yet, so the fit test stays given.
