# C78 · Decomposition by the cut

Decomposition done by cells: a shed partly wakes the stored house it resembles; the cells' states (fits / predicted but
not there / unexplained) draw the cut; the fitting cells become the shared wall on the same cells, and each whole is
rebound by two sampled cells per part. Hypothesis, predictions, findings: [hypothesis.md](hypothesis.md),
[PREREG.txt](PREREG.txt), [findings.md](findings.md). Visual: [decomposition-cut.html](../../../docs/visuals/decomposition-cut.html).

**Run:** `./runall.sh` (about 10 minutes, mostly the comparison cut); `CUTS=top node run.js` takes seconds.

**In short:** the cut found the right parts in every family, the result costs 114 links against 264 for both wholes,
and with the bindings competing as whole memories each roof brings back its own whole (96-97% clean at 64 cells per
column with 200 families). Without the top level of support, the cut is wrong; without competition between whole
memories, a shared part wakes both.
