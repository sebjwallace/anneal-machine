# C132 · Uses from reading

Distillation D-03, V13. Without C131's hidden floor of three letters, learning collapsed because anneal's reuse of
common pairs like "th" was counted as a use, making them so cheap that "the" was never read. Counting a use only when a
piece is read, when it explains the input, removes the collapse and a rule with it. Without any floor, energy over the
whole book is within 1% of before. *Alice* reads better (words whole 53% against 50%), *Buster* a little worse (41%
against 43%). The yardstick is corrected to the contract's own: memory plus the cost of describing everything received,
not only the unseen tenth. It now ranks every setting exactly as the reading measures do.
