# C164 · The memory proposes: hypothesis

Follows [C163](../C163-the-second-row/findings.md). Asked by the owner to take out the most problematic crutch now:
**proposing**, my code deciding which candidate ways of working to try. Until now, for anything the memory had seen,
that meant replaying every stored way of working and varying them by my own enumeration. Search found the rest.

## What changes

My replay of every stored step is gone. **What's tried first is what the memory itself offers:** what it recalls from
the cue plus the page in view, or, when recall stalls, the ways of working whose memories it couldn't choose between
(read from the tie at the moment recall stalled). If none of those settles the worked example, the memory's offers are
tried **varied** (each read in turn held, each of the last two writes dropped). Only when nothing the memory offers
settles does the search run. **Everything is learned in one continuous run:** no ways of working handed over, as the
recent tastes did. The memory is C162's: ways of working bound with what was in view, and ties passing what all
agree on.

**What's still given, declared:** search, for when the memory has nothing to offer (it has to find the very first way
of working of a new kind); the variations tried on an offer (the same menu as before, now applied only to what the
memory offers); the facts; the encoder (pages, the working marked as heat); the fixed architecture. The second row is
left out, as its search is too costly at the reach it needs.

**A limit, stated up front:** this helps learning, where a worked example shows which offer settles. At test there's
no worked answer to check an offer against, so it won't by itself cure "nothing recalled" at test.

## Setup

C158's twelve worked examples per seed ("+", "−", "×" one digit, three long first rows, then again). 4 seeds. Test:
recall from the cue with each test page in view, the recalled way of working run in the circuit, 20 sums per length
(3 to 5 digit tops) of each kind.

## Predictions (fixed before running)

1. **Search runs once per seed,** for the first example (the store is empty). Every later example is settled by recall,
   by the memory's offer, or by the offer varied. In particular, the first subtraction by the offer (the addition's way
   of working, with a new meaning for the sign), and the first multiplication by the varied offer (holding).
2. **The same ways of working are learned as before:** reading for "+" and "−", holding for multiplication.
3. **At test, wrong frames stay near zero, and "nothing recalled" is about where C162 left it,** since nothing here
   changes test-time recall.
