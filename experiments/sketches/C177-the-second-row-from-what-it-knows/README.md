# C177 · The second row from what it knows

One memory learns adding, then times one digit, then the second row of long multiplication (school order). On a
second-row page the start brings up times one digit, which is adapted guided by heat. Writes move only to places still
to be done, and reads only to places holding something. Each part changes on its own, and a change is kept if more of
the working cools. The second row took 412 runs, against 136,922 blind (C172). The first example taught a coincidence,
and the second corrected it. With the learned way of working offered, 200 of 200 second rows were right. From the start
it was 0 of 200, because the view (the sign) can't tell a second row from a first. A fix to how offers are tried was
found by the build check before the run, and is disclosed.
